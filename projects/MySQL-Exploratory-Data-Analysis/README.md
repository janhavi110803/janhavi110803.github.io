# MySQL Exploratory Data Analysis

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a layoffs dataset using MySQL.

The goal of the project is to analyze the cleaned dataset, identify trends and patterns, and generate meaningful insights using SQL queries.

## 🎯 Objectives

- Explore the cleaned layoffs dataset
- Identify companies with the highest layoffs
- Analyze layoffs by year and company
- Identify trends in layoffs over time
- Analyze companies with the highest number of layoffs
- Use SQL to generate meaningful business insights

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

## 🔍 Analysis Performed

### 1. Total Layoffs

Analyzed the overall number of employees laid off across the dataset.

### 2. Maximum Layoffs

Identified companies and records with the highest number of layoffs.

### 3. Yearly Analysis

Analyzed layoffs by year to understand changes over time.

### 4. Company-Level Analysis

Compared total layoffs across different companies.

### 5. Ranking Analysis

Used SQL ranking techniques to identify companies with the highest layoffs for each year.
